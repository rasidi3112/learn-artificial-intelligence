Machine Learning Dasar

Memahami konsep Machine Learning, pembelajaran yang diawasi dan tidak diawasi.

Tingkat: Menengah Durasi: 20 menit

01 Apa itu Machine Learning?

Machine Learning (ML) adalah cabang AI yang memungkinkan komputer untuk belajar dan membuat keputusan tanpa diprogram secara eksplisit untuk setiap tugas. Sistem ML menggunakan algoritma untuk mengidentifikasi pola dalam data dan membuat prediksi atau keputusan berdasarkan pola tersebut.

02 Supervised Learning

Supervised Learning adalah metode di mana model dilatih menggunakan data berlabel. Model belajar dari pasangan input-output untuk membuat prediksi pada data baru.

Contoh Algoritma:
- Linear Regression: Prediksi nilai kontinu (harga rumah)
- Logistic Regression: Klasifikasi biner (spam/bukan spam)
- Decision Trees: Keputusan berbasis aturan
- Random Forest: Ensemble dari decision trees
- Support Vector Machines (SVM): Klasifikasi dengan margin optimal
- Neural Networks: Model terinspirasi otak manusia

03 Unsupervised Learning

Unsupervised Learning adalah metode di mana model menemukan pola dalam data tanpa label.

Contoh Algoritma:
- K-Means Clustering: Mengelompokkan data berdasarkan kesamaan
- Hierarchical Clustering: Pengelompokan bertingkat
- Principal Component Analysis (PCA): Reduksi dimensi
- Association Rules: Menemukan hubungan antar item (market basket analysis)
- Anomaly Detection: Mendeteksi outlier atau data tidak normal

04 Reinforcement Learning

Reinforcement Learning adalah metode di mana agen belajar melalui interaksi dengan lingkungan. Agen menerima reward atau punishment berdasarkan aksinya dan belajar untuk memaksimalkan reward.

Contoh Penerapan:
- Game AI (AlphaGo, OpenAI Five)
- Robot navigasi
- Sistem rekomendasi
- Trading otomatis
- Kontrol kendaraan otonom

05 Proses Machine Learning

  1. Pengumpulan Data: Mengumpulkan data yang relevan
  2. Preprocessing: Membersihkan dan mempersiapkan data
  3. Feature Engineering: Memilih dan membuat fitur penting
  4. Pemilihan Model: Memilih algoritma yang sesuai
  5. Training: Melatih model dengan data
  6. Evaluasi: Menguji performa model
  7. Tuning: Mengoptimalkan hyperparameter
  8. Deployment: Menerapkan model ke produksi

06 Metrik Evaluasi

Klasifikasi:
- Accuracy: Persentase prediksi benar
- Precision: Ketepatan prediksi positif
- Recall: Kemampuan menemukan semua positif
- F1-Score: Harmonic mean precision dan recall

Regresi:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R-squared (R²)
