Computer Vision

Teknologi AI untuk mengenali dan memproses gambar dan video.

Tingkat: Lanjut Durasi: 22 menit

01 Pengenalan Computer Vision

Computer Vision adalah bidang AI yang memungkinkan komputer untuk menginterpretasi dan memahami informasi visual dari dunia nyata, seperti gambar dan video. Teknologi ini meniru cara manusia melihat dan memproses informasi visual.

02 Proses Pengolahan Gambar

  1. Image Acquisition: Mengambil gambar dari kamera/sensor
  2. Preprocessing: Resize, normalisasi, augmentasi
  3. Feature Extraction: Mengekstrak fitur penting
  4. Model Inference: Menjalankan model untuk prediksi
  5. Post-processing: Memproses hasil (NMS untuk deteksi)

Teknik Preprocessing:
- Grayscale conversion
- Histogram equalization
- Noise reduction
- Edge detection (Sobel, Canny)
- Image augmentation (flip, rotate, crop)

03 Tugas Computer Vision

Image Classification:
- Mengkategorikan gambar ke dalam kelas
- Contoh: Kucing vs Anjing, jenis tanaman

Object Detection:
- Mendeteksi dan melokalisasi objek dalam gambar
- Algoritma: YOLO, SSD, Faster R-CNN

Semantic Segmentation:
- Mengklasifikasikan setiap pixel
- Contoh: Segmentasi jalan untuk self-driving car

Instance Segmentation:
- Segmentasi + membedakan instance objek
- Algoritma: Mask R-CNN

Pose Estimation:
- Mendeteksi posisi tubuh manusia
- Contoh: OpenPose, MediaPipe

04 Arsitektur CNN untuk Vision

LeNet (1998): Pionir CNN untuk digit recognition

AlexNet (2012): Breakthrough di ImageNet, ReLU activation

VGGNet (2014): Deeper network dengan 3x3 convolutions

GoogLeNet/Inception (2014): Inception modules untuk efisiensi

ResNet (2015): Skip connections untuk very deep networks

EfficientNet (2019): Balanced scaling untuk akurasi dan efisiensi

Vision Transformer (2020): Transformer untuk gambar

05 Aplikasi Computer Vision

  1. Self-Driving Cars: Tesla, Waymo
  2. Facial Recognition: Face ID, keamanan
  3. Medical Imaging: Deteksi kanker, analisis X-ray
  4. Augmented Reality: AR filters, Pokemon Go
  5. Quality Control: Inspeksi produk di pabrik
  6. Agriculture: Deteksi penyakit tanaman, drone monitoring
  7. Retail: Amazon Go (cashier-less stores)
  8. Sports Analytics: Pelacakan pemain, analisis performa
  9. Document Processing: OCR, digitalisasi
  10. Security: Surveillance, deteksi anomali

06 Tools dan Framework

OpenCV:
- Library open-source untuk computer vision
- Mendukung C++, Python, Java
- Fitur: Image processing, video capture, object detection

MediaPipe (Google):
- Face detection, hand tracking, pose estimation
- Optimized untuk real-time pada device

Torchvision (PyTorch):
- Datasets, transforms, pre-trained models

TensorFlow Hub:
- Repository model pre-trained

Hugging Face:
- Vision Transformers dan model multimodal
