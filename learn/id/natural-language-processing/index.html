Natural Language Processing (NLP)

Bagaimana AI memahami dan memproses bahasa manusia.

Tingkat: Menengah Durasi: 18 menit

01 Pengenalan NLP

Natural Language Processing (NLP) adalah cabang AI yang memungkinkan komputer untuk memahami, menginterpretasi, dan menghasilkan bahasa manusia. NLP menggabungkan linguistik komputasional dengan machine learning dan deep learning untuk memproses teks dan ucapan.

02 Preprocessing Teks

  1. Tokenization: Memecah teks menjadi kata/kalimat
  2. Lowercasing: Mengubah ke huruf kecil
  3. Stopword Removal: Menghapus kata umum (dan, atau, yang)
  4. Stemming: Mengubah kata ke bentuk dasar (berlari → lari)
  5. Lemmatization: Seperti stemming tapi lebih akurat
  6. Part-of-Speech Tagging: Menandai jenis kata
  7. Named Entity Recognition: Mengidentifikasi entitas (nama, lokasi)

03 Representasi Teks

Bag of Words (BoW):
- Representasi sederhana berdasarkan frekuensi kata
- Mengabaikan urutan kata

TF-IDF:
- Term Frequency-Inverse Document Frequency
- Memberi bobot berdasarkan kepentingan kata

Word Embeddings:
- Word2Vec: Skip-gram atau CBOW
- GloVe: Global Vectors
- FastText: Subword embeddings

Contextual Embeddings:
- ELMo: Embeddings dari Language Models
- BERT: Bidirectional representations
- GPT: Generative Pre-trained Transformer

04 Aplikasi NLP

  1. Sentiment Analysis: Menentukan sentimen positif/negatif
  2. Machine Translation: Google Translate, DeepL
  3. Text Summarization: Meringkas dokumen
  4. Question Answering: Menjawab pertanyaan
  5. Chatbots: Customer service otomatis
  6. Speech Recognition: Siri, Google Speech
  7. Text Generation: ChatGPT, Claude
  8. Named Entity Recognition: Ekstraksi informasi
  9. Text Classification: Kategorisasi dokumen
  10. Information Extraction: Mengekstrak data terstruktur

05 Large Language Models (LLM)

LLM adalah model bahasa berskala besar yang dilatih pada dataset teks yang sangat besar.

Contoh LLM:
- GPT-4 (OpenAI): Generasi teks, coding, analisis
- Claude (Anthropic): Asisten AI yang aman
- Gemini (Google): Multimodal AI
- LLaMA (Meta): Open-source LLM
- Mistral: Efficient open-source model

Kemampuan:
- Few-shot learning
- Chain-of-thought reasoning
- Code generation
- Multilingual understanding

06 Tantangan NLP

  • Ambiguitas: Satu kata punya banyak makna
  • Konteks: Makna bergantung konteks
  • Sarkasme dan Ironi: Sulit dideteksi
  • Bahasa Informal: Slang, typo, singkatan
  • Bahasa dengan Sumber Terbatas: Tidak semua bahasa punya data cukup
  • Bias: Model bisa mewarisi bias dari data training
  • Hallucination: LLM bisa menghasilkan informasi salah
