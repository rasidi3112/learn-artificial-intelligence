机器学习基础

理解机器学习的概念，以及监督学习与无监督学习。

等级: 中级 时长: 20 分钟

01 什么是机器学习？

机器学习（ML）是AI的一个分支，它使计算机能够在没有为每个任务明确编程的情况下学习和做出决策。ML系统使用算法识别数据中的模式，并根据这些模式进行预测或决策。

02 监督学习

监督学习是使用标记数据训练模型的方法。模型从输入-输出对中学习，以对新数据进行预测。

算法示例：
- 线性回归：预测连续值（房价）
- 逻辑回归：二分类（垃圾邮件/非垃圾邮件）
- 决策树：基于规则的决策
- 随机森林：决策树的集成
- 支持向量机（SVM）：最优间隔分类
- 神经网络：受大脑启发的模型

03 无监督学习

无监督学习是模型在未标记数据中发现模式的方法。

算法示例：
- K-Means聚类：按相似性分组数据
- 层次聚类：多级分组
- 主成分分析（PCA）：降维
- 关联规则：发现项目间关系
- 异常检测：检测异常值

04 强化学习

强化学习是智能体通过与环境互动来学习的方法。智能体根据其行为获得奖励或惩罚，并学习最大化奖励。

应用：
- 游戏AI（AlphaGo、OpenAI Five）
- 机器人导航
- 推荐系统
- 自动交易
- 自动驾驶车辆控制

05 机器学习流程

  1. 数据收集：收集相关数据
  2. 预处理：清理和准备数据
  3. 特征工程：选择和创建重要特征
  4. 模型选择：选择适当的算法
  5. 训练：用数据训练模型
  6. 评估：测试模型性能
  7. 调优：优化超参数
  8. 部署：将模型部署到生产环境

06 评估指标

分类：
- 准确率：正确预测的百分比
- 精确率：正预测的正确性
- 召回率：找到所有正例的能力
- F1分数：精确率和召回率的调和平均

回归：
- 平均绝对误差（MAE）
- 均方误差（MSE）
- R平方（R²）
