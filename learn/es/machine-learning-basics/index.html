Módulo 02 / 15

Fundamentos de Machine Learning

Comprende los conceptos de Machine Learning y el aprendizaje supervisado y no supervisado.

Nivel: Intermedio Duración: 20 min

01 ¿Qué es Machine Learning?

Machine Learning (ML) es una rama de la IA que permite a las computadoras aprender y tomar decisiones sin estar programadas explícitamente para cada tarea. Los sistemas de ML utilizan algoritmos para identificar patrones en los datos y hacer predicciones basadas en esos patrones.

02 Aprendizaje Supervisado

El Aprendizaje Supervisado es un método donde el modelo se entrena usando datos etiquetados. El modelo aprende de pares entrada-salida para hacer predicciones en datos nuevos.

Algoritmos de Ejemplo:
- Regresión Lineal: Predecir valores continuos (precios de casas)
- Regresión Logística: Clasificación binaria (spam/no spam)
- Árboles de Decisión: Decisiones basadas en reglas
- Random Forest: Conjunto de árboles de decisión
- Support Vector Machines (SVM): Clasificación con margen óptimo
- Redes Neuronales: Modelos inspirados en el cerebro

03 Aprendizaje No Supervisado

El Aprendizaje No Supervisado es un método donde el modelo encuentra patrones en datos no etiquetados.

Algoritmos:
- K-Means Clustering: Agrupación de datos por similitud
- Clustering Jerárquico: Agrupación multinivel
- Análisis de Componentes Principales (PCA): Reducción de dimensionalidad
- Reglas de Asociación: Encontrar relaciones entre elementos
- Detección de Anomalías: Detectar valores atípicos

04 Aprendizaje por Refuerzo

El Aprendizaje por Refuerzo es un método donde un agente aprende interactuando con un entorno. Recibe recompensas o castigos basados en sus acciones y aprende a maximizar las recompensas.

Aplicaciones:
- IA de Juegos (AlphaGo, OpenAI Five)
- Navegación de robots
- Sistemas de recomendación
- Trading automatizado
- Control de vehículos autónomos

05 Proceso de ML

  1. Recopilación de Datos: Reunir datos relevantes
  2. Preprocesamiento: Limpieza y preparación de datos
  3. Ingeniería de Características: Creación de características importantes
  4. Selección de Modelo: Elección del algoritmo
  5. Entrenamiento: Entrenar el modelo con datos
  6. Evaluación: Probar el rendimiento
  7. Ajuste: Optimizar hiperparámetros
  8. Despliegue: Implementar en producción

06 Métricas

Clasificación:
- Exactitud: Porcentaje de predicciones correctas
- Precisión: Exactitud de predicciones positivas
- Recall: Capacidad de encontrar todos los positivos
- F1-Score: Media armónica de precisión y recall

Regresión:
- Error Absoluto Medio (MAE)
- Error Cuadrático Medio (MSE)
- R-cuadrado (R²)
